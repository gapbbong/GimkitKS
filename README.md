# 🎮 퀴즈 아레나

Gimkit처럼 **교사 화면(큰 스크린) + 학생 폰**으로 즐기는 교실용 퀴즈 게임 플랫폼입니다.
Gimkit의 코드/에셋은 사용하지 않고, "퀴즈를 풀어 게임을 진행한다"는 공개된 플레이 방식만 참고해 새로 만들었습니다.
최대 40명 동시 접속(20명 봇으로 6개 게임 전부 테스트), 서버는 교사 PC 1대만 있으면 됩니다.

## 실행

`start.bat` 더블클릭 (또는 `npm install` → `npm start`). 처음에만 설치가 필요합니다.

1. 교사 PC 브라우저에 **교사 화면**(`http://localhost:3000/host`)이 열리면 방 코드와 QR이 보입니다.
2. 학생은 같은 Wi-Fi에서 폰으로 **QR을 찍거나** 화면에 표시된 주소(예: `http://10.x.x.x:3000`)로 접속해 이름을 입력합니다.
3. 교사가 게임과 시간을 고르고 **게임 시작**.
4. 끝나면 결과/시상대가 나오고, "다른 게임 고르기"로 계속 진행합니다.

> 학생 폰이 접속이 안 되면 Windows 방화벽에서 Node.js(포트 3000)의 **개인 네트워크** 허용을 확인하세요.
> 주소가 여러 개 보이면 화면의 드롭다운에서 학생 폰과 같은 대역(보통 `192.168.x.x` 또는 `10.x.x.x`)을 고르세요.

## 6가지 게임

| 게임 | 방식 |
|---|---|
| 💰 머니 퀴즈 | 정답으로 돈을 벌고, 상점에서 정답 상금·연속 보너스·오답 방어를 업그레이드 |
| 🦘 **점프 오르기** | 발판을 밟으며 하늘 끝까지 점프. 금색 ? 발판의 퀴즈를 맞히면 로켓 +약 200m. 모두 같은 산을 오르고 교사 화면에 고도 경쟁이 실시간 표시 |
| 🎣 **낚시왕** | 정답이면 낚싯줄 던지기 → 입질 → 타이밍 바 미니게임. 연속 정답일수록 희귀 어종 확률 상승 (장화 3점 ~ 용왕 1000점) |
| 🏎️ 퀴즈 레이싱 | 정답마다 전진, 오답은 충돌, 5연속은 터보, 바나나로 앞차 견제 |
| 🐲 보스 레이드 | 모두 협동. 정답 = 공격, 오답/보스 공격 = 하트 감소, 0이면 7초 기절. 보스를 쓰러뜨리면 더 센 보스 등장 |
| 🏴‍☠️ 보물 대작전 | 정답이면 상자 3개 중 선택: 코인·잭팟·도둑질·바꿔치기·방어막·폭탄 |

## 문제 편집

교사 화면 로비의 **문제 편집**에서 직접 입력하거나 파일을 불러옵니다. 한 줄에 한 문제:

```
질문 | 정답 | 오답1 | 오답2 | 오답3
```

기본 문제 50개는 `questions.json`에 있습니다. (서버는 정답을 학생 폰에 보내지 않고 서버에서 채점합니다.)

## 구조

- `server.js` : HTTP + WebSocket, 방/플레이어/문제/채점/타이머
- `games/*.js` : 게임별 서버 규칙 (점수 계산, 보스 AI, 물고기 확률 등)
- `public/play.*`, `public/games/*.js` : 학생 폰 화면
- `public/host.*` : 교사 화면
- 새 게임 추가: `games/`에 서버 규칙, `public/games/`에 학생 화면을 추가하고 `games/index.js`와 `play.html`에 등록
